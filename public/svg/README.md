# SVG Icon Assets

This folder is the local fallback set for technology and brand marks used by
the site.

The current files are a mixed historical set. Most brand-style SVGs follow
Simple Icons-like naming, while a few are custom marks or exports from other
tools. For new icons, prefer package-managed Iconify collections such as
`@iconify-json/simple-icons` or `@iconify-json/devicon` when possible. Keep a
local SVG only when the exact color, shape, or brand mark is not available from
the collection, and record the source and license in the commit or PR.
