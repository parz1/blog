# SVG Icon Assets

This folder is the local fallback set for technology and brand marks used by
the site.

The current files are a mixed historical set. Most brand-style SVGs follow
Simple Icons-like naming, while a few are custom marks or exports from other
tools. For new icons, prefer a package-managed source first. If only a few
icons are needed, keep local SVGs to avoid bundling an entire icon collection.

The Python, Google Colab, Jupyter, PyTorch, and NumPy icons were derived from
the Simple Icons data shape and kept locally because the homepage only needs a
small subset. Keep a local SVG only when the exact color, shape, or brand mark
is not available from the existing local set, and record the source and license
in the commit or PR.
