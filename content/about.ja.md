# Zhou Lei

東京大学大学院学際情報学府 / 情報学環の修士課程に在籍し、東京を拠点にしています。

> I build software for thinking.
>
> 目標は、AI が人の記憶、学習、研究、意思決定の一部になるようなシステムを作ることです。

私の関心は、人工知能、人間の認知、プロダクトデザインの交差点にあります。

人がよりよく考え、継続的に学び、知的なシステムと一緒に働けるようにする道具を作ることに興味があります。

研究アイデアを実際に使えるプロダクトへ進めることが好きです。背後の技術システムと、日常の中で役に立つ体験の両方を設計します。

現在の研究では、multimodal AI と human-centered computing を扱っています。特に、声や表情のような信号が、人の状態や行動をコンピュータが理解する助けになる方法に関心があります。

## Focus

- AI-native products and agent systems
- Personal knowledge and memory systems
- Local-first software
- Multimodal human-AI interaction
- Human-centered AI
- Rapid prototyping from 0 → 1
- Chinese · Japanese · English

## Now

東京大学で修士課程に取り組みながら、AI-native software の未来を探っています。

特に、研究とプロダクト開発のあいだにある領域に関心があります。新しいアイデアが、人が実際に使える道具になる場所です。
